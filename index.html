Questions

What does an integration and AI automation engineer do?

I connect the apps a business already runs on, such as CRMs, accounting, email and marketing tools, so data moves between them automatically, and I build AI agents that research, qualify and act on that data. The work covers API integration, workflow automation and AI-agent orchestration.

Which automation platforms do you work with?

Zapier, n8n, Make, Integry, Squig and GoHighLevel, plus custom code in Python and SQL when a platform is not the right fit.

Which apps can you integrate?

I have shipped or maintained integrations with 300+ apps, including Salesforce, HubSpot, Dynamics 365, Pipedrive, Zoho CRM, Xero, MYOB, QuickBooks, Gmail, Outlook, Slack and Microsoft Teams. If an app has an API (REST, GraphQL or webhooks), I can usually integrate it.

Can you build AI agents for lead generation and sales outreach?

Yes. I have built production agents that enrich new signups, research companies across multiple sources, discover net-new leads with buying signals, and qualify leads against an ideal customer profile before writing personalised emails and loading them into Instantly sequences.

Can you get my app verified by Microsoft, Google or Meta?

Yes. I have taken connectors through Microsoft Entra ID publisher verification, Google OAuth scope verification and Meta App Review, and kept them approved as each platform changed its policies.
