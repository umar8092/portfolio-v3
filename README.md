# Muhammad Umar, portfolio (v3 design)

Integration and AI automation portfolio. The hero shows a different live visual on each load (3D graph, orbit, magnetic wall or category map). Add `?hero=orbit`, `?hero=wall`, `?hero=map` or `?hero=graph` to the address to pin one.

Plain HTML, CSS and JavaScript. Open `index.html` or serve the folder with `python3 -m http.server`.

Brand logos belong to their respective owners and are shown only to indicate which apps have been integrated.
